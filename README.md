# CS 174A Final Project

Project Idea: 3D Suika Game

Team Members:
- Spandan Patel
- Jeff Huang
- Marissa Li

Suika is an addictive puzzle game where players strategically drop 11 kinds of fruit (e.g. cherries, strawberries, grapes, dekopons, persimmons, apples, pears, peaches, pineapples, melons, watermelons) of varying, exponentially increasing sizes, aiming to match fruits into larger ones. When the same fruit type collides, they combine to form a larger fruit the next size up. Only the five smallest fruits (cherries, strawberries, grapes, dekopons, and persimmons) appear in the drop queue. Each time these fruits combine, they increase the player’s score. The game ends if a fruit crosses the top line, usually caused by a large un-merged fruit. Game strategy includes to avoid large fruits like pineapples and melons from trapping smaller ones at the bottom, as the difference in radius makes it hard to manage space. With colorful visuals, satisfying sound effects, and 3d graphics, our version of the Suika Game will create a fun and memorable experience for the player.
